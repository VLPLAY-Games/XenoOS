## Обзор

Это система командной строки (CLI) для взаимодействия с различными системными компонентами, такими как файловая система, Wi-Fi, SD-карты и диагностика системы. Система поддерживает различные команды для управления файлами, директориями и системными настройками.

Система разработана для всей линейки микроконтроллеров ESP32, но специально оптимизирована для модели ESP32-C3.

## Возможности

- Управление файлами (создание, удаление, переименование файлов)
- Диагностика системы
- Управление Wi-Fi подключением
- Взаимодействие с SD-картой
- История команд
- Информация о памяти и процессоре

## Установка

### Альтернативная установка для ESP32-C3
Если вы используете **ESP32-C3**, можно установить систему с помощью **esptool** или аналогичного инструмента. Выполните следующие шаги:

1. Перейдите в раздел [Releases](https://github.com/VLPLAY-Games/XenoOS/releases) на GitHub.
2. Скачайте последний архив прошивки.
3. Можно прошить либо **объединённую прошивку**, либо каждый файл отдельно:
   - Чтобы прошить объединённую прошивку:
     ```bash
     esptool.py --chip esp32c3 --baud 921600 write_flash 0x0 XenoOS.merged.bin
     ```
     Если у вас несколько подключенных устройств, укажите порт вручную:
     ```bash
     esptool.py --chip esp32c3 --port /dev/ttyUSB0 --baud 921600 write_flash 0x0 XenoOS.merged.bin
     ```
   - Чтобы прошить файлы отдельно:
     ```bash
     esptool.py --chip esp32c3 --baud 921600 write_flash \
       0x1000 XenoOS.bootloader.bin \
       0x8000 XenoOS.partitions.bin \
       0x10000 XenoOS.bin
     ```
     Если у вас несколько устройств, укажите порт вручную:
     ```bash
     esptool.py --chip esp32c3 --port /dev/ttyUSB0 --baud 921600 write_flash \
       0x1000 XenoOS.bootloader.bin \
       0x8000 XenoOS.partitions.bin \
       0x10000 XenoOS.bin
     ```
После завершения установки система должна запуститься на вашем устройстве.

### Стандартная установка через Arduino IDE

Чтобы установить и настроить систему, выполните следующие шаги:

1. **Необходимые условия**:
    - Должна быть установлена **Arduino IDE 2.x**.
    - Убедитесь, что установлен **ESP32 core версии 3.1.0 или выше**.
    - Установите следующие библиотеки:
      - `buildTime` версии 1.0.0
      - `ESPping` версии 1.0.5
      - `ESP32-targz` версии 1.2.6

2. **Настройка оборудования**:
    - Система разработана для **семейства ESP32**, но специально оптимизирована для **ESP32-C3**.
    - Для модуля MicroSD используйте **SD-карту емкостью не более 4ГБ**.
    - Подключение MicroSD к **ESP32-C3** осуществляется по стандартной распиновке.

3. **Шаги установки**:
    1. Клонируйте репозиторий на локальный компьютер:
    ```bash
    git clone https://github.com/VLPLAY-Games/XenoOS.git
    cd XenoOS
    ```
    
    2. Откройте файл `XenoOS.ino` в **Arduino IDE 2**.
    
    3. Выберите **ESP32-C3 Dev Module** в качестве целевого устройства в Arduino IDE.
    
    4. В **Инструментах** установите следующие параметры:
    - **USB CDC On Boot**: "Включено"
    - **Частота процессора**: "160MHz (WiFi)" (по умолчанию)
    - **Core Debug Level**: "None" (по умолчанию)
    - **Очистка Flash перед загрузкой скетча**: "Отключено" (по умолчанию)
    - **Частота Flash**: "80MHz" (по умолчанию)
    - **Режим Flash**: "QIO" (по умолчанию)
    - **Размер Flash**: "4MB (32Mb)" (по умолчанию)
    - **JTAG адаптер**: "Отключен" (по умолчанию)
    - **Схема разделов**: "Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)"
    - **Скорость загрузки**: "921600" (по умолчанию)
    - **Режим Zigbee**: "Отключен" (по умолчанию)
    
    5. Нажмите **Загрузить**, чтобы прошить систему на ваш ESP32-C3.

После завершения установки система должна быть запущена на вашем устройстве.



## Использование

После установки взаимодействуйте с системой через последовательный порт (скорость 115200) в **Putty** или в **Serial Monitor** Arduino IDE (не рекомендуется), вводя команды в терминал. Ознакомьтесь со "Списком команд" выше для доступных команд и примеров использования.

## Диагностика

Для выполнения диагностики системы используйте команду:

```bash
system diagnostic
```

Эта команда запустит тесты для проверки состояния компонентов, таких как ESP32, SPIFFS, SD-карта и EEPROM.
